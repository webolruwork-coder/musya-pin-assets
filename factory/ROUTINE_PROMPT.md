# Pinterest Daily Factory — Claude Routine

Рабочая папка: канонический репозиторий `musya-pin-assets` с этой инструкцией.

## Цель

Поддерживать очередь из семи оригинальных Pinterest-пинов для Telegram `@musya_gpt`. Один запуск обрабатывает максимум один manifest. Не создавай публикацию, если `factory/config.json → publishing.enabled` равно `false`.

## Алгоритм запуска

1. Выполни `npm run factory:init` и `npm run factory:next`.
2. Если активного запуска нет, создай его командой:

   ```bash
   npm run factory:create -- --slug <короткий-английский-slug>
   ```

3. На стадии `queued` открой Pinterest через Playwright MCP по `search.query` из manifest. Если анонимная выдача не показывает карточки, используй поисковую выдачу с ограничением домена `pinterest.com` как fallback и зафиксируй это в истории запуска:
   - просмотри не более `search.result_limit` карточек;
   - исключи рекламу;
   - остановись через `timeout_seconds`, даже если результатов меньше;
   - запиши URL и SHA-256 fingerprint, затем кратко опиши общие паттерны;
   - не скачивай и не копируй чужой пин как основу финального изображения;
   - переведи manifest в `research_ready`.
4. Подготовь новый сюжет и русский image prompt в фирменной логике существующих пинов. Заполни title, description и 7–10 ключевых фраз. Переведи в `concept_ready`.
5. Создай оригинальное вертикальное изображение 2:3 через ImageGen. Сохрани исходник внутри папки запуска и переведи в `generated`.
6. Используй локальный SVG-рендерер: изображение остаётся главным, текст живёт в спокойной области, CTA ведёт к `@musya_gpt`. Финал — JPEG или PNG ровно `1000×1500`. Переведи в `rendered`.
7. Выполни `npm run factory:validate -- <run-id>`.
   - При ошибке оставь `needs_review`, запиши причину и прекрати запуск.
   - После успешной автоматической проверки визуально проверь мобильную читаемость, отсутствие логотипов, водяных знаков и анатомических дефектов.
8. Выполни `npm run factory:prepare-host -- <run-id>`, закоммить и отправь публичный файл. Затем выполни `npm run factory:confirm-host -- <run-id>`; команда переведёт manifest в `hosted` только после успешной HTTP-проверки изображения.
9. Если публикация выключена, остановись и сообщи ссылку на manifest и превью.
10. Если публикация включена, проверь Metricool на дубль по `id`, выбери бренд по `blog_id` и через Metricool MCP поставь пин в очередь на доску из manifest. Числовой `boardId` не требуется: используй точное имя доски. Запиши post ID и время, переведи в `scheduled`.

## Запреты

- Не листай бесконечную выдачу Pinterest.
- Не используй Pinterest API.
- Не публикуй напрямую в Pinterest: только Metricool.
- Не перескакивай через стадии и не используй `--force`.
- Не повторяй reference URL из других manifest.
- Не меняй глобальный шаблон по результатам одного пина.
- Не пушь в `main` и не включай публикацию самостоятельно.
